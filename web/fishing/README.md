# Pixel Fishing — как устроена игра

Браузерная 8-битная рыбалка, управляется контроллером M5 по Bluetooth. Подходит любой из трёх:

| Устройство | Прошивка | Имя в списке Bluetooth |
|---|---|---|
| M5StickS3 | `StickS3_BMI270_events.ino` | `StickS3-Rod` |
| M5StickC Plus2 | `StickCPlus2_MPU6886_events` | `StickCP2-Rod` |
| M5Cardputer ADV | `CardputerADV_BMI270_events` | `Cardputer-Rod` |

Протокол у всех одинаковый, игра находит их одинаково.

## Как запустить

Откройте `index.html` в **Chrome** или **Edge** (двойной клик по файлу).
Если подключение к стику не работает, запустите в папке `web`:

```
python -m http.server
```

и откройте `http://localhost:8000/fishing/index.html`.

После любого изменения в файлах просто обновите страницу (**F5**).
Если что-то сломалось — нажмите **F12**, вкладка **Console**: там будет красная строка
с названием файла и номером строки, где ошибка.

## Ход игры (состояния)

```
aimX ──TAP2──▶ aimY ──TAP2──▶ ready ──HIGH-G──▶ casting ──▶ waiting
                                                              │
     ┌──────────────── TAP2 (вытащить) ◀─────────────────────┤
     ▼                                                        ▼ (время вышло)
  reeling ◀── не успел / сорвалась ── fight ◀── ORIENT или HIGH-G ── bite
     │                                  │
     ▼                                  ▼ (turns оборотов катушки, по редкости)
   aimX                              caught ──▶ photo ──TAP2──▶ aimX (или win, если набрано 20 кг)
```

**Червячки (жизни).** В начале их `FISH.worms` (5). Каждый раз, когда рыба уходит
(не успел подсечь или она сорвалась при вываживании), пропадает один червячок —
это в `loseFish()` в `js/game.js`. Когда червячков 0, после сматывания включается
состояние `gameover`; двойной тап начинает новую игру (`restartGame()`).
Червячки рисуются в правом верхнем углу — `drawWorms()` в `js/draw.js`.

**Цель.** Наловить `FISH.goalKg` (20) кг рыбы. Общий вес — `game.totalWeight`,
показан под червячками. Когда цель набрана, после фото включается состояние `win`.

**Сложность** (`DIFFICULTIES` в `js/config.js`) — это окно подсечки `hookWindow`:
лёгкий 3 с, нормальный 1.5 с, эпический 0.75 с, «самая быстрая рука на Диком Западе» 0.45 с.
В коде текущий уровень — `game.difficulty`.

**Пакет** (`js/floaters.js`). Раз в `FLOATERS.interval` секунд (сейчас 3 минуты) по воде проплывает пакет.
Поймать его можно двумя способами: забросить поплавок прямо в него или, пока поплавок
в воде, сделать подсечку (HIGH-G) в момент, когда пакет проплывает через поплавок.
Насколько точно надо попасть — `FLOATERS.hitX` / `hitY`. В пакете червячки (все снова на месте),
а если они и так все — прикормка.

**Время суток** (`js/daytime.js`, настройки `DAYTIME` в `js/config.js`). Часы идут по кругу:
ночь → рассвет → день → закат → ночь; сколько настоящих секунд длится каждая часть — `DAYTIME.parts`
(сейчас вся смена 9 минут, игра начинается в 5:12, перед рассветом). Часы видны под весом улова.
Солнце встаёт слева в `sunrise` и садится правее центра в `sunset`; на горизонте оно крупнее,
с широким ореолом, а по воде бежит золотая дорожка. Ночью — звёзды (плывут по небу вместе с луной),
луна с серебряной дорожкой (каждую ночь новая фаза), изредка падающая звезда, светлячки
у острова и фонарь рыбака, вокруг которого светлее. На зорьке рыба чаще плещется.
Цвета неба, облаков и освещения по часам — `SKY_KEYS` в начале `daytime.js`.

Как это рисуется: сцена рисуется как днём, но небо оставляется прозрачным; `lightScene()`
перекрашивает её под время суток (вода при этом отражает небо), потом `drawSkyBehind()`
подкладывает под неё небо. Подсказки и шкалы рисуются уже после — они не темнеют.

События по времени суток: `onDayPart('night', () => ...)` — вызывается, когда наступила
часть суток (`'dawn'`, `'day'`, `'dusk'`, `'night'`); `atHour(6, () => ...)` — когда часы дошли
до 6:00; `dayPart()` — что сейчас. Так, например, на рассвете кричит петух (`ambience.js`).

**Ночной костёр** (`js/campfire.js`, настройки `CAMPFIRE` в `js/config.js`) — ивент, который бывает
только ночью. Когда наступает ночь, после текущей попытки (или сразу, если игрок выбирает место)
камера показывает кострище на берегу. Игра включает микрофон стика, и нужно **дуть в стик**:
каждый выдох (`EV.BLOW`) раздувает огонь, пока дуешь — пламя вспыхивает. После 15–20 выдохов
(`blowsMin`/`blowsMax`) костёр разгорается, микрофон выключается, над огнём появляется рыба
(последняя пойманная) на вертеле. Теперь **крутить стик кистью**, как катушку, 10–15 секунд
(`cookMin`/`cookMax`) — рыба поворачивается и румянится. Потом рыбак её съедает (хруст, остаётся
скелет), и игра возвращается к рыбалке. Костёр остаётся гореть рядом с рыбаком и освещает остров;
в `outHour` (7 утра) гаснет и немного дымит. Если микрофон не работает, тройной тап зажигает
костёр сразу.

**Звуки природы** (`js/ambience.js`). Ветер порывами, плеск волн о берег, шелест камыша,
днём птицы (на рассвете — целый хор), утром кукушка, ночью сверчки, лягушки и сова, у костра — треск огня.
Всё синтезирует браузер, файлов нет. Громкость — `DAYTIME.ambienceVol`, клавиша **V** — вкл/выкл.

**Ведро** (`js/bucket.js`, настройки `BUCKET` в `js/config.js`). После фото каждой рыбы —
вид от первого лица сверху вниз, как с комаром: на траве ведро с водой и уже пойманными рыбами (ведро каждый раз в новом
месте), снизу тянется рука с рыбой в пальцах и плавно ездит из стороны в сторону. **LOW-G** (резко опустить
стик), когда рыба над ведром, — рыба падает в ведро и только тогда идёт в улов (`landFish()`).
Промах — рыба шлёпается на траву, прибегает пиксельный кот и утаскивает её: в улов она не идёт.
Если не отпустить рыбу за `BUCKET.time` секунд, рука устаёт и роняет её сама.

**Комар** (`js/mosquito.js`, настройки `MOSQUITO` в `js/config.js`). После
ведра с каждой `MOSQUITO.every`-й рыбой (сейчас каждой 3-й попавшей в ведро) слышен писк («ЗЗЗЗ...»), и открывается сцена с рукой: над ней
мечется комар, отскакивая от краёв экрана; его скорость — `mosquitoSpeed` уровня сложности (`DIFFICULTIES`).
Рывок (HIGH-G), когда комар над ладонью, — сверху опускается вторая рука и прихлопывает его.
Тогда после возвращения к озеру бросаем прикормку, только вместо хлеба летит комар
(`game.baitKind`). Попытка одна: промах (или не хлопнул за `MOSQUITO.time` секунд) — комар
хихикает и улетает.
Писк комара — `buzzStart / buzzSet / buzzStop` в `js/sound.js`, он едет слева направо вместе с комаром.

**Прикормка** (`js/bait.js`, настройки `BAIT` в `js/config.js`). Если поймать пакет,
когда все червячки на месте, в нём прикормка: игрок выбирает сектор двойными тапами
(`baitAimX` → `baitAimY`), затем делает **HIGH-G** (рывок, как при забросе) — `baitReady` → `baitThrow`.
Сектор бурлит и действует 30 секунд (`BAIT.time`); под конец бурление стихает. Заброс в него: 75% элитная,
20% эпическая рыба, 5% — обычный розыгрыш.

**Редкость улова** (`RARITIES` в `js/config.js`). Сразу при подсечке (`rollFish()` в `js/game.js`)
выпадает редкость, потом вес в её пределах, потом вид рыбы, у которого эта
редкость есть в списке `rarity` (`FISH_TYPES`). От редкости и веса зависит, сколько оборотов
крутить при вываживании (`turns`: чем тяжелее рыба внутри своей редкости, тем ближе к максимуму).
Цвет рамки фото — `frame` редкости. В улов рыба идёт, только когда её вытащили (`landFish()`).

| Редкость | Шанс | Вес | Оборотов | Рамка |
|---|---|---|---|---|
| обычная | 85% | 0.25–0.4 кг | 30–45 | серая |
| редкая | 10% | 0.4–1.5 кг | 45–80 | синяя |
| элитная | 4% | 1.5–3 кг | 80–100 | фиолетовая |
| эпическая | 1% | 3–5 кг | 150 | золотая |

Каждое состояние описано в `js/states.js` одним блоком:

```js
имяСостояния: {
  hint: () => T('ключ'),         // подсказка (текст из i18n.js)
  alert: true,                   // подсказка мигает жёлтым
  enter() { ... },               // один раз при входе
  onEvent(id, code) { ... },     // пришло событие от стика
  update(dt, t) { ... },         // каждый кадр
},
```

## События стика

В коде они пишутся как `EV.ИМЯ`:

| Имя | Что сделали со стиком |
|---|---|
| `EV.TAP1`, `EV.TAP2`, `EV.TAP3` | Одиночный, двойной, тройной тап |
| `EV.HIGH_G` | Резкий рывок |
| `EV.LOW_G` | Свободное падение |
| `EV.ORIENT` | Повернули (поменялась ориентация) |
| `EV.ANY_MOT` / `EV.NO_MOT` | Начали двигать / перестали |
| `EV.SIG_MOT` | Долгое движение (несли, шли) |
| `EV.FLAT` | Положили экраном вверх (`code` = 1) / подняли (`code` = 0) |
| `EV.REEL` | Крутят стик кистью, как катушку: `code` = скорость в десятых оборота в секунду, 0 = перестали |
| `EV.BLOW` | Дуют в микрофон стика: `code` = сила выдоха 1..255, 0 = выдох закончился. Микрофон включается только по команде игры (`setMic(true)` в `js/controller.js`) |

**Катушка.** Во время вываживания (`fight`) игра включает на стике катушку — `setReel(true)`
в `js/controller.js`. Стик включает гироскоп и 10 раз в секунду присылает `EV.REEL` со скоростью
вращения, направление не важно. Игра копит обороты в `game.turns`; рыба поймана на
`turns` оборотах (по редкости, см. таблицу выше). Общего таймера нет: если не крутить дольше `FISH.fightMaxGap`
секунд (в зелёной фазе), рыба сходит.
Вращение медленнее `FISH.reelMinSpeed` об/с не засчитывается, чтобы лёгкое покачивание стика
не подматывало леску.

**Натяжение лески.** Над шкалой вываживания горит индикатор, справа от него — иконка удочки.
Зелёный и прямая удочка — крути как хочешь. Время от времени рыба тянет: сначала индикатор
`TENSION.warnTime` секунду плавно краснеет, а удочка начинает гнуться — это предупреждение.
Потом он красный (на пару секунд, звук «бип-бип», подсказка «НАТЯЖЕНИЕ!»), удочка согнута и
трясётся. Когда натяжение отпускает, индикатор за `TENSION.relaxTime` секунды плавно
зеленеет, и удочка выпрямляется. Пока он красный, крутить можно только медленно, не быстрее `TENSION.maxSpeed` об/с,
или переждать. Крутишь быстрее — леска рвётся, червячок пропадает. Сразу после подсечки
натяжения не бывает (`TENSION.firstMin`), а после покраснения есть ещё `TENSION.grace` секунды
на реакцию. Рисует индикатор `drawTension()` в `js/draw.js`.
Все числа — в `TENSION` в `js/config.js`.
Со старой прошивкой без катушки вместо оборотов считаются повороты `EV.ORIENT`.

## Рецепты

### Тексты и языки
Весь текст лежит в `js/i18n.js`, в коде он берётся через `T('ключ')`:
```js
say(T('msg_escaped'), C.bad);
```
Новый текст — новый блок со всеми языками сразу:
```js
msg_bonus: { en: 'BONUS!', ru: 'БОНУС!', zh: '奖励！', ja: 'ボーナス！' },
```
Если забыть какой-то язык — в консоли (F12) появится предупреждение, а в игре
будет английский текст. Проще всего попросить Claude: «добавь строку … на все языки».
Выбранный язык и сложность запоминаются в браузере.

### Поменять баланс
Всё в `js/config.js`, блок `FISH`. Например, чтобы рыба в зоне клевала быстрее:
```js
biteZoneMin: 8, biteZoneMax: 12,
```

### Добавить вид рыбы
1. `js/config.js`, массив `FISH_TYPES` — добавьте строку (в `rarity` — какой редкости может быть):
```js
{ name: 'fish_trout', rarity: ['rare', 'elite'], body: '#f8a8a8', stripe: '#a81000', fin: '#787878' },
```
2. `js/i18n.js` — название на всех языках:
```js
fish_trout: { en: 'TROUT', ru: 'ФОРЕЛЬ', zh: '鳟鱼', ja: 'マス' },
```

### Сделать, чтобы стик реагировал на новое событие
Найдите нужное состояние в `js/states.js` и допишите в его `onEvent`.
Например, тройной тап во время ожидания подбрасывает прикормку:
```js
waiting: {
  ...
  onEvent(id) {
    if (id === EV.TAP2) setState('reeling');
    if (id === EV.TAP3) {
      game.waited += 3;                 // ждать на 3 секунды меньше
      addRipple(game.floatX, game.floatY, 2);
      say(T('msg_bait'), C.good);      // строку msg_bait добавить в i18n.js
    }
  },
```

### Добавить новое состояние
1. В `js/states.js` добавьте блок, например `bonus: { hint: () => T('hint_bonus'), update(dt, t) { ... } }`.
2. Перейдите в него из другого состояния: `setState('bonus')`.
3. Если оно должно выглядеть по-особому — допишите отрисовку в `js/draw.js`
   (там проверки вида `if (s === 'fight') ...`).

### Добавить плавающий предмет
Раз в `FLOATERS.interval` секунд (`js/config.js`) по воде проплывает предмет.
Если попасть в него поплавком — он цепляется на крючок и срабатывает его эффект.
1. Нарисуйте картинку в `js/sprites.js` (как `BAG`) и палитру (как `BAG_PAL`).
2. Добавьте блок в `FLOATER_TYPES` в `js/floaters.js`, например бутылка, дающая +1 червячка:
```js
{
  name: 'item_bottle',             // + перевод в i18n.js
  sprite: BOTTLE, pal: BOTTLE_PAL,
  speed: 20,                     // быстрее пакета
  chance: 2,                     // попадается в 2 раза чаще пакета
  effect() {
    game.worms = Math.min(FISH.worms, game.worms + 1);
    say(T('msg_plus_worm'), C.good);   // строку добавить в i18n.js
    sfx.pickup();
  },
},
```

### Показать сообщение по центру экрана
```js
say(T('ключ'));                   // белым
say(T('ключ'), C.bad);            // красным
say(T('ключ'), C.accent, 16);     // жёлтым и крупно
```

### Добавить звук
В `js/sound.js` добавьте строку в `sfx`, затем вызывайте `sfx.имя()`:
```js
bonus: () => beep(880, 0.2, { type: 'triangle' }),
```

### Протестировать без стика
Кнопка «Играть с клавиатуры» на последнем шаге стартового окна:

| Клавиша | Событие |
|---|---|
| Пробел | TAP2 |
| H или Enter | HIGH-G |
| L | LOW-G |
| O | ORIENT |
| R (держать) | крутить катушку быстро, 6 об/с |
| T (держать) | крутить катушку медленно, 0.9 об/с (при натяжении) |
| B (держать) | дуть в микрофон (BLOW) |
| N / M | NO MOT / ANY MOT |
| F | положить / поднять (FLAT) |
| G | отладка: сетка, рыбная зона, таймеры (работает и со стиком) |
| J | промотать время суток на час вперёд (работает и со стиком) |
| V | звуки природы вкл/выкл |

Новую клавишу можно добавить в `KEYBOARD_EVENTS` в `js/controller.js`.

## Как попросить помощи

Опишите, что должно происходить, словами — например, «если во время ожидания
три раза тапнуть, рыба клюёт быстрее». Удобно указать, в каком состоянии
(`waiting`, `fight` …) и на какое событие стика.
